# Rhombiverse ユーザーガイド

Rhombiverse とその双子の [Polyhedraverse](https://polyhedraverse.vercel.app) は、同じ幾何学を 2 つの見方で眺めるサイトです。Rhombiverse は**風景**：あらゆる方向へ広がる格子そのもの。Polyhedraverse は**肖像画ギャラリー**：その格子に住む形を、1 つずつ間近で見せます。

ここでは、どのピースも本物の結晶格子の上で空間をすき間なく埋めます。そのため、ピースは格子に空きがある場所にしか置けません。タップでピースを追加し、長押しで取り除き、作ったものを 2D から 6D までのさまざまな表示で眺めてみましょう。

このガイドの前半ではよく使う操作を順に説明し、後半ではすべての操作を一覧にしています。

画面上のボタン名は、アプリに表示されるとおりに書いています（アプリがまだ翻訳していないものは英語のままです）。

## はじめに

### 次元を選ぶ

**ENTER** を押すと次元の選択画面が開きます。ゆっくり回転する立体で、その面が **2D**、**3D**、**4D**、**5D**、**6D** になっていて、それぞれアイコンが付いています。面にカーソルを合わせる（タッチ画面では長押しする）と名前が表示されるので、選びたい面をタップします。ドラッグすると立体が回り、ほかの面が手前に来ます。

あとから切り替えるには **メニュー → Change Dimension** か、左上の **Wizard** を使います。Wizard には各次元のすべての格子が、そのピースの回転するワイヤーフレームとともに並んでいます。

### 最初のピースを置く

空のワールドには、最初のピースが置かれる場所に**シアンの輪郭**が表示されます。それをタップしてください。あとは、どれかのピースの面（2D では辺）をタップすると、その反対側に隣のピースが追加されます。

ピースは 1 つずつ置いていきます。3D では最初に **RD**（菱形十二面体）が選ばれています。いま置くピースは左下の **Shape** ボタンに表示されています。タップすると別のピースを選べます。

### ピースを取り除く

- **スマートフォン・タブレット：** ピースを長押しします。
- **マウス：** ピースを右クリックします。右クリックはどのモードでも取り除きます。

直前の変更を取り消すには、右下の **Undo**（↶）をタップします。押し続けると、何段階も一度にさかのぼれます。取り消しの履歴は次元ごとに別々なので、2D で取り消しても 3D や 4D の作品には影響しません。

### カメラを動かす

- **回転：** 1 本指でドラッグ、またはマウスの左ボタンでドラッグ。
- **ズーム：** ピンチ、またはスクロールホイール。
- **移動：** 2 本指でドラッグ。

## 何を作るか選ぶ

### 格子ごとのピース

**2D：** Parallelogram（平行四辺形）、Triangle（三角形）、Hexagon（六角形）、Kite（凧形）、Kagome（かごめ）のタイル。上部のパネルから選び、それぞれ最大 4 つの格子角（90°、70.53°、63.43°、60°）で使えます。

**3D：**

| 格子 | ピース |
|---|---|
| FCC | Rhombic Dodecahedron（RD、菱形十二面体）、Hemi RD、Hourglass、RD Quarter、Cube、Pyramid |
| RD Dual | Cuboctahedron（CO、立方八面体）、Octahedron（八面体） |
| BCC | Truncated Octahedron（TO、切頂八面体） |
| BCC Interstitial | Flattened Octahedron、Disphenoid |
| Elongated Dodecahedron | Elongated Dodecahedron（ED、長菱形十二面体） |
| Hexagonal | Hex Prism（六角柱） |
| Rhombohedral | Rhombohedra（菱面体） |
| Pyrochlore（3D かごめ） | Truncated Tetrahedron（切頂四面体。あいだの四面体は自動で追加されます） |

**4D：**

| ワールド | ピース |
|---|---|
| Z4 | Tesseract（4D の立方体） |
| D4 | 24-cell、16-cell |
| Hyper-pyrochlore（4D かごめ） | 5-cell、Truncated 5-cell、Bitruncated 5-cell |

FCC で試してみましょう。Pyramid を 6 つ置いて Cube を作ります。次に Cube の各面に Pyramid を 1 つずつ足すと、RD になります。その 6 つをまた取り除くと Cube に戻ります。

**RD Quarter** は、RD を分割してできる 4 つの菱面体の 1 つです。RD の角の近くをタップするとその角が埋まり、次に Quarter の面をタップすると、その面の向こう側に鏡像が置かれます。鏡像はかならず RD 格子の上に来るので、Quarter をセルからセルへと伸ばしていけます。Mirror（鏡像）に加えて Copy（複製）も使える自由な菱面体格子には、**Rhombohedra** を使ってください。

### 色

左下の**色ボタン**をタップすると、14 色から選べます。選んだ色は、いま置いているピースに結び付きます。設定の **ピースの種類に応じて色を自動割り当て** をオンにすると、色を選ぶまでは、ピースの種類ごとに別々の色で始まります。

## 作品を眺める

| 表示 | 見えるもの | オンにする方法 |
|---|---|---|
| World View | カラー、半透明、スケルトン | World View ボタンをタップして切り替え |
| Lattice View | 作品と、選んだピースを 1 段外側に置ける空き場所すべて | Lattice View ボタンをタップしてピースを切り替え |
| X-Ray | 切断面。平面を構造の中へドラッグできます（斜めにも） | X-Ray ボタン（⛶） |
| Spherical | 各ピースを球に近い形で表示 | Spherical ボタン（◯） |
| Duality | この結晶構造が投影する非周期タイリング | Duality ボタン（◐） |
| BCC Lattice | FCC 格子の中に入れ子になった体心立方格子 | BCC Lattice ボタン（⬡） |
| Dualize | FCC と BCC を入れ替え | 設定 → Dualize Preview |

設定には **断面表示** もあります。軸を選び、スライダーで切断位置を動かし、**反転** にチェックを入れると反対側が見えます。

## 4D に入る

1. 次元の選択画面、Wizard、または **メニュー → Change Dimension** で **4D** を選びます。
2. ワールドを選びます：Tesseract（Z4）、24-cell または 16-cell（D4）、あるいは Hyper-pyrochlore のピース。
3. 3D と同じように作ります。面をタップすると、隣の 4D セルが追加されます。

画面下部に 4D パネルが表示されます。

- **断面 / 投影** で 4D の見え方を切り替えます。**断面**（既定）は、現在の深さでの 3D 断面を表示します。**投影** は 4D セル全体を影として表示し、影の面をタップするとその向こうに作れます。投影では **平行** と **透視** も切り替えられます。
- **スライダー** は、その上のボタンが示す操作をします。**W深度** は断面を 4 次元方向に動かし、**XW**・**YW**・**ZW** は 4 次元方向に回転させます。便利な位置でカチッと止まります。**FCC** と書かれた位置は通常の 3D の RD ワールド、**Pyrochlore** と書かれた位置は 3D の Pyrochlore ワールドです。
- **4Dをリセット** ですべてを最初の位置に戻します。
- **情報** を押すとパネルが開き、いまのワールドと置くピース、作ったもの、断面の位置（W深度 または 投影）、XW/YW/ZW の回転角、最後にタップまたは配置したセルの 4D 中心座標が表示されます。

## 5D と 6D に入る

5D と 6D は **準結晶** です。5 次元または 6 次元の立方格子を 3D 空間で切った断面で、ピースはすき間なく空間を埋めますが、模様は決して繰り返しません。

- **6D** は正二十面体準結晶です。ピースは 2 種類の黄金菱面体：**prolate**（細長い）と **oblate**（平たい）。
- **5D** は十角形準結晶です。ペンローズ・タイリングの層で、**thick**（太い）と **thin**（細い）の菱形柱でできています。

1. 次元の選択画面、Wizard、または **メニュー → Change Dimension** で **5D** か **6D** を選びます。
2. 水色の輪郭をタップして最初のピースを置き、面をタップすると隣のピースが追加されます。5D では、上面と下面をタップすると上下に層が加わります。

形は自分では選びません。どの場所にどのピースが入るかは、タイリングが決めます。

画面下部にパネルが表示されます。

- **スライダー** は、その上のボタンが示す操作をします。**フェイゾン 1**・**フェイゾン 2**・**フェイゾン 3**（6D のみ）は、断面を隠れた次元の方向へ横にずらします。ピースが入れ替わり、断面から出ていくものと入ってくるものがあります。断面で隠れたピースは消えたわけではなく、戻せば再び現れます。**近似結晶** は周期的な結晶（1/1、2/1、3/2、5/3、8/5 …）を順に切り替え、右端の **τ**（真の準結晶）にどんどん近づきます。
- **構築 / ウィンドウ** で **ウィンドウ表示** に切り替わり、隠れた次元が見えます。ウィンドウは 6D では菱形三十面体、5D では五角形の組です。ピースの頂点がそれぞれ点になり、ウィンドウの内側（その頂点は断面内）なら白、外側なら赤で表示されます。フェイゾンのスライダーを動かすと、ピースが現れたり消えたりするのに合わせて、点がウィンドウの境界を横切るのが見えます。
- **5Dをリセット** / **6Dをリセット** でスライダーを最初の位置（τ でフェイゾン 0）に戻します。
- **情報** には、ワールド、作ったもの、断面内のピース数と断面で隠れているピース数、フェイゾンと近似結晶の設定、ウィンドウ表示では内側にある頂点の数が表示されます。召喚したアイテムも一覧になり、タップするとその設定までスライドして戻ります。

**Lattice View** は周りのタイリングを 1 段外側まで幽霊のように表示し、フェイゾンを動かすとそれも入れ替わります。**World View** は 3D と同じです。

### カタログ

5D と 6D では、左下のボタンで **カタログ** が開きます（Wizard の 5D・6D カードからも開けます）。アイテムは 4 種類です。

- **ゾーン多面体：** タイリング自身のピースでできた形。黄金菱面体 1 個から菱形三十面体まで、5D では菱形・六角形・八角形・十角形の柱もあります。
- **ポリトープ：** 高次元ポリトープの影。たとえば 6 次元正軸体の影は正二十面体です。影はピースを妨げずにタイリングの上に重なり、断面内にある頂点が光ります。長押しで削除できます。
- **ブリッジ：** 超角柱。ポリトープをもう 1 つの次元方向へ 1 段伸ばした形（たとえば 5 次元正軸体の角柱）で、ポリトープと同じく影として置かれます。
- **頂点スター：** ピースが 1 つの頂点で出会うすべての形（5D では 7 種類、6D では 24 種類）。周りのピースを 1 周分・2 周分付けたものもあります。見出しをタップすると一覧が開きます。

どのアイテムにもシリアル番号があります。欄に番号を入力して **召喚** をタップすると、そのアイテムに直接進めます。

アイテムを選ぶと、準結晶の中でそれが実際に現れる場所に **金色の輪郭** が表示されます。構築物をタップするとその近くで最も近い場所へ輪郭が移り、輪郭をタップすると通常のピースとして置かれます。アイテムが別の近似結晶のものなら、先にスライダーがそこまでスライドします。**召喚をキャンセル** でやめられます。**Undo** 1 回で取り消され、スライダーも元の位置に戻ります。

**つなぐ**（ピースが 2 つ以上あるとパネルに表示）は 2 つのアイテムを結びます。それぞれのピースをタップすると、その間を結ぶ最短のタイルの鎖が 1 つのコネクタとして置かれます。**Undo** 1 回で取り消せます。

## 黄金菱面体

3D ペンローズ・タイリングの 2 ピースで作る 3D ワールドです。Wizard の 3D 画面かピースのホイールから選びます。水色の輪郭をタップし、面をタップすると、ピースのメニューで選んだ**細長い**か**平たい**ピースが加わります。**ペンローズ判定**は、真の非周期タイリングに属するピースを緑、外れたピースを赤で示します。Lattice View は周りの真のタイリングを表示し、幽霊をタップすると置けます。

## 作品を保存する

ワールドは変更のたびに、すべての次元ぶん、このブラウザに自動で保存されます。同じ端末・同じブラウザでサイトを開き直すと元に戻ります。

**設定** では：

- **ワールドをエクスポート** は、すべて（3D の全格子、2D のタイル、4D・5D・6D の作品）を 1 つのファイルに保存します。バックアップや、別の端末への移動に使えます。
- **ワールドをインポート** は、エクスポートしたファイルを開きます。**Undo** でインポートを取り消せます。
- **新しいワールド** は、空のワールドからやり直します。コーナーホイールの **Clear World**（⊘）も同じです。Undo で元に戻せます。

## 数学を学ぶ

- **Almanac：** すべてのピースと格子の背後にある数学と幾何学。メニュー → Almanac から開きます。
- **What's New** には最近の変更が並んでいます。

# 操作一覧

## 画面のボタン

| 操作 | 内容 |
|---|---|
| Wizard（左上） | 次元と格子を、それぞれのピースとともに見て回る |
| Shape（左下） | いま置くピース。タップで変更 |
| 色（左下） | 作るときの色。タップで変更 |
| Lattice View | Off と、各ピースの表示を順に切り替え |
| Rhombohedra の付け方 | Rhombohedra のときだけ表示：Copy と Mirror を切り替え |
| Undo（↶、右下） | タップで現在の次元を 1 段階取り消し。押し続けるとさらにさかのぼる |
| メニュー | メニューホイールを開く（キーボード：Tab または Space） |

## コーナーホイール

隅の小さなホイールをドラッグして回し、面をタップして使います。

| 記号 | 操作 |
|---|---|
| ⚙ | 設定 |
| ⛶ | X-Ray |
| ◐ | Duality |
| ⬡ | BCC Lattice |
| ◇ | メニュー |
| ⊘ | Clear World |
| ↻ | Reload（何かが止まって見えるときに使います） |
| ◯ | Spherical |
| — | World View、Cuboctahedron Build |

## メニューホイール

メニューは菱形十二面体です。各面が 1 つのセクションで、面をタップすると開き、**Home** で戻ります。**Settings** と **Almanac** はいつも上の面にあります。

| セクション | 内容 |
|---|---|
| Home | Piece、Color、Change Dimension |
| Piece | RD family、Cube、Pyramid、TO、Flattened Octahedron、Disphenoid、CO、Octahedron |
| RD family | RD、Hemi RD、Hourglass、RD Quarter、ED、Hex Prism、Rhombohedra、Pyrochlore |
| Change Dimension | 2D、3D、4D、5D、6D |

## 設定

| 設定 | 内容 |
|---|---|
| 視点の感度 | カメラの回転速度 |
| Y軸反転 | 縦方向のドラッグを逆にする |
| 視野角 | カメラのレンズの広さ |
| グラフィック品質 | 低・中・高 |
| FPSメーターを表示 | フレームレートの表示 |
| 音量 | 音の大きさ |
| 言語 | English、日本語、Español、Français、한국어、中文、Русский（ようこそ画面とこのガイドの上部にある 🌐 ピッカーでも変更できます） |
| ピースの種類に応じて色を自動割り当て | ピースの種類ごとに別の色を付ける |
| 断面表示、軸、位置、反転 | 1 つの軸に沿った切断面 |
| Build Cuboctahedron、Dualize Preview | 特別な作成モード |
| 新しいワールド、ワールドをエクスポート、ワールドをインポート | やり直し、バックアップ、復元（すべての次元） |

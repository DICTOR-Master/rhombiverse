# Rhombiverse 用户指南

Rhombiverse 和它的孪生网站 [Polyhedraverse](https://polyhedraverse.vercel.app) 是观察同一种几何的两种方式。Rhombiverse 是**风景**：向四面八方延伸的晶格本身。Polyhedraverse 是**肖像画廊**：住在这些晶格里的形状，一次一个，近距离展示。

在这里，每个部件都在真实的晶体晶格上无缝地填满空间，所以只能把部件放在晶格有空位的地方。轻点添加部件，长按移除部件，再用不同的视图从 1D 到 6D 查看你的作品。

本指南的第一部分介绍常用操作，第二部分列出所有控件。

按钮名称按应用中显示的样子书写（应用尚未翻译的名称保留英文）。

## 入门

### 选择维度

按下 **ENTER** 后会打开维度选择器：一个缓慢旋转的立体，它的面分别是 **1D+**、**2D**、**3D**、**4D**、**5D** 和 **6D**，每个面都有图标。将鼠标悬停在面上（触屏上长按）可以看到名称，然后轻点你想要的面。拖动可以转动立体，把其他面转到前面。

之后可以通过 **菜单 → Change Dimension** 切换，或者使用左上角的 **Wizard**，它列出了每个维度的所有晶格，以及各自部件的旋转线框。

### 放置第一个部件

空的世界里会在第一个部件的位置显示一个**青色轮廓**。轻点它。然后轻点任意部件的一个面（在 2D 中是一条边），就会在它的另一侧添加一个相邻部件。

部件一次放一个。3D 一开始选中的是 **RD**（菱形十二面体）。当前要放置的部件显示在左下角的 **Shape** 按钮上；轻点它可以换一个部件。

### 移除部件

- **手机或平板：** 长按部件。
- **鼠标：** 右键点击部件。右键在任何模式下都会移除。

要撤销上一次更改，请轻点右下角的 **Undo**（↶）。按住可以一次回退好几步。每个维度都有自己的撤销历史，所以在 2D 中撤销不会影响你在 3D 或 4D 中的作品。

### 移动镜头

- **旋转：** 单指拖动，或按住鼠标左键拖动。
- **缩放：** 双指捏合，或使用滚轮。
- **平移：** 双指拖动。

## 选择要搭建的内容

### 按晶格分类的部件

**1D+ 信号**（Wizard → 1D+ → Signal）：一行承载消息的子弹形单元。在底部一行输入消息（会替换之前的消息，可照常编辑）：它以幽灵单元出现（即它的摩尔斯电码，不必会），下一个是橙色。点按它可逐个放置，按**发送**（或回车）则放下其余单元，让消息沿线远去（■ 停止）。输入框为空时，显示这行的内容。眼睛按钮在**外部**（从后上方看：线条沿屏幕向上延伸，在远处变细，淡淡的雾把它延续到无限）和**内部**（在隧道中：单元从你正下方经过，向远处的一点升去）之间切换。长按移除一个单元，后面的线会合拢：因为它是一维的。

消息旁的圆形**脉冲键**就是电报键：点按为点，按住为划；稍停开始新字母，停得更久开始新单词。你敲出的内容会以点和划（· –）显示在消息栏中，字母之间为空格，单词之间为 /；可像普通文字一样在那里编辑（也可输入 . 和 -）。发送旁的小卷轴按钮打开**摩尔斯电码**词汇表：每个字母、数字和符号及其点划；点按一个即可加入消息。信号播放时，消息会在屏幕顶部随到达逐字显示。 在内部，拖动可环顾四周，捏合（或滚动）可沿隧道前后移动，双指上下拖动（或 Shift + 滚动）可升高或降低；松开后视角会缓缓复原。

**1D+ 构造**（Wizard → 1D+ → Construct · Square）：用一维单元一次一格、一次一条线地搭出正方形。只显示你所在的线，下一个单元是橙色：点按即可填满。第一条边沿 **X** 向屏幕上方延伸；在拐角处连接点发光，**Y** 加入（X 保留），已建的线变淡；按顺时针继续：沿顶边，沿对边向下（与第一条平行的第二条 X 线），再沿底边返回。环一闭合，整个正方形出现并被填满，**在 2D 中打开**可把它带到 2D 的正方形瓷砖。长按撤销最后一格。

接着是立方体：正方形闭合后，视角转到斜侧，**Z** 从起点角升起。它的第一条棱一次点按一格；之后每点按一次就填满一整条棱：其余三条 Z 棱，然后是顶部正方形。每条棱都有带编号的名称（X1、Y2、Z3 …）；完成的棱变淡，刚完成的那条保持实心直到下一条。立方体闭合后整体显示，并带有淡淡的面。 闭合后立即成为晶格的一部分：周围的立方体以淡影铺满空间（**晶格**按钮可隐藏或显示）。 闭合的正方形也有晶格按钮，显示正方形铺满平面。Wizard 旁的指示显示你已建到哪一维（**1D+**、**1D+/2D**、**1D+/2D/3D**、**1D+/2D/3D/4D**）。撤销旁的 **⊘** 清除整个构建以重新开始（撤销可恢复），Wizard 下方的 **Signal | Construct** 切换可在两个一维世界之间切换。

接着是超立方体：立方体闭合后（**在 3D 中打开**可把它带到 3D 的立方体零件），第四个方向 **W** 从起点角向内伸出：W 以透视方式绘制，所以第二个立方体较小，位于第一个之内。它的第一条棱一次点按一格，之后每点按一次一条棱：其余七条 W 棱，然后是内部立方体。闭合后立即成为晶格的一部分；点按使它沿 W 缓慢旋转，内外立方体互换位置（再点按停止），**在 4D 中打开**可把它带到 4D 的超立方（Z4）世界。

**1D+ Construct · Kagome**（Wizard → 1D+ → Construct · Kagome）：先用手搭一个六边形，每点按一次一格，第一条边朝屏幕上方，顺时针，一笔连成。它用到笼目的三个方向：**X**，第一个角处加入 **Y**，然后是 **XY**（X 与 Y 的合成，所以仍是二维）。闭合它就是二维的时刻：晶格按钮显示蜂窝，**在 2D 中打开**可把它带到 2D 的六边形瓷砖。接着笼目之星在它周围生长，每点按一次一条棱（没有新方向）：伸到每个尖角，再回到下一个角，笼目的两条线在那里相交。星闭合后立即成为笼目晶格的一部分，**在 2D 中打开**可把它带到笼目瓷砖。 接着沿 **Z** 进入烧绿石（三维笼目），节奏相同：先是六边形部分，立在你的六边形上的截角四面体（四个六边形、四个三角形；Z 的第一条棱手动，其余两次点按），这是三维的时刻；然后是它三角形上的小四面体，四个一次点按，星的尖角上三个，顶上一个。合在一起是一个大四面体，即 3D 的烧绿石零件：它立即成为烧绿石晶格的一部分，**在 3D 中打开**可带它过去。 然后沿 **W** 进入超烧绿石（四维笼目），再次同样的节奏：躯干是截角五胞体（五个截角四面体，你的是其中之一，和五个四面体；W 以向内的透视绘制），W 的第一条棱手动，其余两次点按；然后是四肢，每个四面体上一个小五胞体，五个一次点按。合在一起是一个大五胞体：点按使它沿 W 旋转，**在 4D 中打开**可把它带到超烧绿石世界。躯干青色，四肢金色，一直如此。Construct 的每个系列（正方形、笼目、RD）各自保存进度。

**1D+ Construct · RD**（Wizard → 1D+ → Construct · RD）：旗舰系列。先像正方形一样用手搭出 RD 自己的菱形，从它的 70.53° 角开始，第一条边朝屏幕上方，顺时针：这是二维的时刻（晶格按钮显示菱形晶格，**在 2D 中打开**可带到 RD 菱形角度的平行四边形）。然后沿 **Z** 进入菱形十二面体，用 RD 自己的语法：先是躯干，内部的立方体（青色；它的棱是菱形的短对角线；Z 的第一条棱手动，其余一次点按），再是四肢，六个面上各一个棱锥（金色，六个一次点按），棱锥的棱就是 RD 的棱。闭合后立即成为周围十二个 RD 的晶格，**在 3D 中打开**会在那里放一个 RD。 然后沿 **W**：RD 是 24 胞体的影子，把它展开就得到 24 胞体。立方体的每个角沿 W 一分为二，两侧各一个，两个立方体构成超立方体（躯干：W 的第一条棱手动，其余角一次完成）。然后是四肢：六个顶点一次点按连接两侧，再点按一次沿 W 加上两个新顶点。这就是 24 胞体，96 条棱，沿 W 旋转，RD 作为它的影子留下；**在 4D 中打开**可带到 D4 世界。

**2D：** Parallelogram（平行四边形）、Triangle（三角形）、Hexagon（六边形）、Kite（筝形）和 Kagome（笼目）瓷砖，在顶部面板中选择，每种最多有四个晶格角度（90°、70.53°、63.43° 和 60°）。

**2D 万花筒**（Wizard → 2D → Kaleidoscope）：一个独立的世界。用彭罗斯的胖菱形和瘦菱形、五边形、三角形、六边形和正方形搭建（边长全都相同，任意两块都能边对边拼合）。点按的位置决定一切：靠近某块的边，所选的块就放到边的另一侧；点在空处，它就松散落下，滑动到挨着伙伴对齐为止。块之间从不重叠。镜子把作品映成万花筒：镜子按钮在环（○，1 到 12 面镜子）和三面镜子的三角形（△60°、△45°、△30°，铺满屏幕重复）之间切换，用滑块设定；**旋转**让作品相对镜子转动，**↻** 让它一直转，**≈** 把所有块摇松，重新排成新图案。**Safe**（仅彭罗斯形状）让菱形遵守彭罗斯的匹配规则，始终构成真正的彭罗斯镶嵌。**Lattice View** 显示镜线，并以轮廓标出块能放下的每个位置。

**2D 展开图**（Wizard → 2D → Nets）：从二维到三维。在面板中选择一个立体：**沃罗诺伊胞**，立方体、RD 和 TO（截角八面体），即简单、面心和体心立方晶格中填满空间的胞；它的展开图以淡淡的虚影显示。沿着它：点按用一维单元逐边搭出第一个面，之后每点按一次搭出下一个面。展开图完成后点按，它就折叠成立体（指示显示 **2D/3D**）；**折叠滑块**可手动折叠和展开，**在 3D 中打开**可把完成的立体带过去。长按撤回一个面（或展开）。每个立体各自保存进度。 **柏拉图立体**是第二组：正四面体、正八面体、正二十面体、正十二面体和立方体。**在 3D 中打开**只在 3D 世界有对应零件的立体上出现（立方体、RD、TO、正八面体）。Undo 旁的 **⊘** 清除当前的展开图。

**Paint**（除 1D+ 外的所有维度）：底部一排的画笔，或颜色轮中央的 Paint 开关，可以给已放好的块重新上色。打开它，选一种颜色，点按一块；关掉它即可继续搭建。颜色设置会切换到 Pick，让每块显示自己的颜色。（Shells 和 Golden Rhombohedra 按色带和类型上色，因此那里没有 Paint。）当底部一排的位置被连接方式切换占用时（3D 的 Rhombohedra 和 Pyrochlore），画笔就在它正上方；在 4D 中它在 4D 面板里。

**3D：**

| 晶格 | 部件 |

| FCC | Rhombic Dodecahedron（RD，菱形十二面体）、Hemi RD、Hourglass、RD Quarter、Cube、Pyramid |
| RD Dual | Cuboctahedron（CO，立方八面体）、Octahedron（八面体） |
| BCC | Truncated Octahedron（TO，截角八面体） |
| BCC Interstitial | Flattened Octahedron、Disphenoid |
| Elongated Dodecahedron | Elongated Dodecahedron（ED，伸长十二面体） |
| Hexagonal | Hex Prism（六棱柱） |
| Rhombohedral | Rhombohedra（菱面体） |
| Pyrochlore（3D 笼目） | Truncated Tetrahedron（截角四面体；它们之间的四面体会自动添加） |

**4D：**

| 世界 | 部件 |
|---|---|
| Z4 | Tesseract（4D 立方体） |
| D4 | 24-cell、16-cell |
| Hyper-pyrochlore（4D 笼目） | 5-cell、Truncated 5-cell、Bitruncated 5-cell |

在 FCC 上试试：放六个 Pyramid 组成一个 Cube。然后在 Cube 的每个面上各加一个 Pyramid，它就变成了 RD。再把这六个移除，就回到 Cube。

**RD Quarter** 是 RD 分割成的 4 个菱面体之一。在 RD 的某个角附近轻点，就会填上那个角；再轻点某个 Quarter 的面，就会在那个面的另一侧放上它的镜像。镜像总是落回 RD 晶格上，所以你可以让 Quarter 一格一格地生长。如果想要既能 Mirror（镜像）也能 Copy（复制）的自由菱面体晶格，请使用 **Rhombohedra**。

### 颜色

部件的颜色由设置中的 **配色** 决定：**青色**（全部青色，默认）、**类型**（每种部件各有颜色，可在显示的列表中修改）或 **自选**（每个部件保持放置时的颜色）。轻点左下角的**颜色按钮**可从 15 种颜色中选择：在青色模式下会切换到自选，在类型模式下会改变当前部件类型的颜色。切换模式不会丢失部件放置时的颜色。

## 进入 4D

1. 在维度选择器、Wizard 或 **菜单 → Change Dimension** 中选择 **4D**。
2. 选择一个世界：Tesseract（Z4）、24-cell 或 16-cell（D4），或者一个 Hyper-pyrochlore 部件。
3. 像在 3D 中一样搭建：轻点一个面，添加相邻的 4D 胞。

屏幕底部会出现 4D 面板。

- **截面 / 投影** 切换观看 4D 的方式。**截面**（默认）显示当前深度处的 3D 截面。**投影** 把完整的 4D 胞显示为影子；轻点影子的面就能从那里继续搭建。在 投影 中还可以在 **平行**和 **透视**之间切换。
- **滑块** 的作用取决于它上方的按钮：**W 深度** 让截面沿第四维移动，**XW**、**YW** 和 **ZW** 让它朝第四维旋转。它会在有用的位置自动停靠。标着 **FCC** 的位置就是普通的 3D RD 世界，标着 **Pyrochlore** 的位置就是 3D Pyrochlore 世界。
- **重置 4D** 把一切恢复到初始位置。
- **Paint**（画笔）在 24 胞体、16 胞体和超烧绿石零件时出现在这个面板里（因为它们的连接方式切换占用了底部的涂色位置）。
- **信息** 打开一个面板，显示当前的世界和要放置的部件、你已搭建的内容、截面所在位置（W 深度 或 投影）、XW/YW/ZW 旋转角度，以及你最后轻点或放置的胞的 4D 中心坐标。

## 进入 5D 和 6D

5D 和 6D 是 **准晶**：把五维或六维的立方晶格穿过 3D 空间切开。部件无缝地填满空间，但图案永远不会重复。

- **6D** 是二十面体准晶。它的部件是两种黄金菱面体：**prolate**（细长）和 **oblate**（扁平）。
- **5D** 是十边形准晶：一层层的彭罗斯铺砌，由 **thick**（宽）和 **thin**（窄）两种菱形棱柱组成。

1. 在维度选择器、Wizard 或 **菜单 → Change Dimension** 中选择 **5D** 或 **6D**。
2. 轻点青色轮廓放下第一块，然后轻点一个面来添加相邻的一块。在 5D 中，轻点顶面或底面会在上方或下方加一层。

形状不由你选择：铺砌会决定每个空位放哪一种部件。

屏幕底部会出现一个面板。

- **滑块** 的作用取决于它上方的按钮。**相位子 1**、**相位子 2** 和 **相位子 3**（仅 6D）让截面沿隐藏的维度横向移动：部件会翻转，有的离开截面，有的进入。被截面隐藏的部件并没有被删除，滑回去它们就会重新出现。**近似晶体** 在一系列周期晶体（1/1、2/1、3/2、5/3、8/5 …）之间切换，它们越来越接近最右端的真正准晶 **τ**。
- **搭建 / 窗口** 切换到 **窗口视图**，显示隐藏的维度。在 6D 中窗口是一个菱形三十面体，在 5D 中是一组五边形。你的部件的每个顶点都是一个点：在窗口内（该顶点在截面中）为白色，在窗口外为红色。拖动相位子滑块，就能看到部件出现和消失时，点穿过窗口的边界。
- **重置 5D** / **重置 6D** 把滑块放回起点：τ 处的相位子 0。
- **信息** 显示世界、你已搭建的内容、截面中有多少块以及截面隐藏了多少块、相位子和近似晶体的设置，在窗口视图中还显示有多少顶点在窗口内。你召唤过的条目也会列出：轻点一项即可滑回它的设置。

**Lattice View** 以虚影显示向外一步的周围铺砌，拖动相位子时它们也会翻转。**World View** 与 3D 中相同。

### 目录

在 5D 和 6D 中，左下角的按钮会打开 **目录**（Wizard 中的 5D 和 6D 卡片也能打开它）。目录里有四类条目：

- **环带多面体：** 由铺砌自身的部件组成的形状，从单个菱面体到菱形三十面体；在 5D 中还有菱形、六边形、八边形和十边形棱柱。
- **多胞体：** 高维多胞体的影子，例如 6 维正轴体，它的影子是一个正二十面体。影子叠在铺砌上而不阻挡部件，位于截面中的顶点会亮起。长按即可移除。
- **桥：** 超棱柱，即把多胞体沿另一个维度延伸一步得到的形状，例如 5 维正轴体棱柱。它们和多胞体一样以影子放置。
- **顶点星：** 部件在一个顶点相遇的每一种方式（5D 中 7 种，6D 中 24 种），也有带着外围一圈或两圈部件的版本。轻点标题即可展开列表。

每个条目都有一个序号。在输入框中输入序号，再轻点 **召唤** 即可直接找到它。

选中一个条目后，你的准晶中它真正出现的位置会显示一个 **金色轮廓**。轻点你的搭建物，轮廓会移到附近最近的位置；轻点轮廓，它就会以普通部件的形式放下。如果条目属于另一个近似晶体，滑块会先滑到那里。**取消召唤** 可以停止。一次 **Undo** 即可撤销，并把滑块滑回原来的位置。

**连接**（有两块以上时出现在面板中）把两个条目连起来：各轻点其中一块，它们之间最短的真实块链就会作为一个连接件放下。一次 **Undo** 即可撤销。

## 层壳

一个搭建**外壳**的 3D 世界：一层层菱形十二面体（RD），从你的第一块向外计数，每一层都有自己的色带。在 Wizard 的 3D 屏幕中选择它。

- **+ 层**填满下一层，**− 层**移除最外层。**外壳**选择计层方式：**步数**（截半立方体：13、55、147 … 块）、**距离**（趋向球体），或目标形状（正四面体、立方体、正八面体、RD 或截角八面体）。**修整**把外壳精确切平成那个形状。
- **分割**模式：轻点一块，再选择**分割**方式（二分之一、三分之一、四分之一、六分之一、八分之一、十二分之一、十六分之一、二十四分之一或四十八分之一）；**旋转**改变切法。在搭建模式下，**部件**菜单也能单独放置碎片。
- **比例**用更大的 RD（×2 到 ×4）搭建。对选中的块使用**合并为 ×2 / ×3**，会显示大 RD 的轮廓，**确认合并**后换成一个大 RD；分割菜单可以再把它拆开。
- **信息**里有环形图：轻点一个环可隐藏或显示那一层以查看内部，可移除任意一层，并选择色带颜色。

## 黄金菱面体

用 3D 彭罗斯铺砌的两块搭建的 3D 世界。在 Wizard 的 3D 屏幕中选择它。轻点青色轮廓，再轻点一个面，就会加上部件菜单中选的**细长**或**扁平**块。**彭罗斯检查**把属于真正非周期铺砌的块标为绿色，偏离的标为红色；Lattice View 显示周围真正的铺砌，轻点虚影即可放置。

## 保存你的作品

每次更改后，你的世界（所有维度）都会自动保存在这个浏览器中。在同一台设备、同一个浏览器上重新打开网站，它就会回来。

在 **设置** 中：

- **导出世界** 把所有内容（每个 3D 晶格、你的 2D 瓷砖以及 4D、5D、6D 作品）保存到一个文件中。可以用来备份，或把世界转移到另一台设备。
- **导入世界** 打开导出的文件。**Undo** 可以撤销导入。
- **新建世界** 用空世界重新开始。角落轮盘上的 **Clear World**（⊘）作用相同。Undo 可以恢复。

## 学习数学

- **Almanac：** 每种部件和晶格背后的数学与几何。从 菜单 → Almanac 打开。
- **What's New** 列出最近的更改。

# 控件参考

## 屏幕按钮

| 控件 | 作用 |
|---|---|
| Wizard（左上） | 浏览各个维度和晶格及其部件。旁边的橙色大字显示你所在的维度 |
| Shape（左下） | 当前要放置的部件。轻点更换 |
| 颜色（左下） | 搭建颜色。轻点更换 |
| Lattice View | 在 Off 和每种部件的视图之间循环 |
| 连接方式切换 | 仅在可用多种方式连接的零件时显示（Rhombohedra：Copy / Mirror；Pyrochlore：小四面体 / 整个四面体；24 胞体 / 16 胞体；超烧绿石的三种五胞体）：轻点切换 |
| Undo（↶，右下） | 轻点撤销当前维度的一步。按住可继续回退 |
| Paint（画笔） | 给已放好的块重新上色：打开、选色、轻点一块。在底部一排连接方式切换的位置；需要那个切换时，它就在正上方（4D 中在 4D 面板里） |
| Signal \| Construct（Wizard 下方，仅 1D+） | 在两个 1D+ 世界之间切换 |
| ⊘ 清除（Undo 旁，1D+ 和 Nets） | 清空当前 1D+ 世界重新开始（在 Nets 中为当前展开图）；Undo 可恢复 |
| 菜单 | 打开菜单轮盘（键盘：Tab 或空格） |

## 菜单轮盘

菜单是一个菱形十二面体。每个面是一个分区：轻点一个面打开它，用 **Home** 返回。**Settings** 和 **Almanac** 总在顶部的面上。

| 分区 | 内容 |
|---|---|
| Home | Piece、Color、Change Dimension |
| Piece | RD family、Cube、Pyramid、TO、Flattened Octahedron、Disphenoid、CO、Octahedron |
| RD family | RD、Hemi RD、Hourglass、RD Quarter、ED、Hex Prism、Rhombohedra、Pyrochlore |
| Change Dimension | 2D、3D、4D、5D、6D |
